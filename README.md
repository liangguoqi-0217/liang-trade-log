# 交易执行记录本 · liang-trade-log

一个纯静态的期货交易执行记录网页。**当晚筛品种写条件，次日只等触发，盘后对照记一笔。**

- 网页代码在本仓库（公开，用于托管 Pages）
- 你的交易数据存在另一个**私有**仓库 `liang-trade-log-data` 的 `journal.json` 里，别人看不到
- 换电脑只需要：打开网址 → 填一次 Token → 点「拉取」

在线地址：<https://liangguoqi-0217.github.io/liang-trade-log/>

---

## 一、换电脑：三步取回全部数据

1. 浏览器打开上面的网址
2. 右上角 **设置** → 找到「GitHub 同步」→ 把 Token 粘贴进去 → 点「保存」
3. 点 **「从 GitHub 拉取」** → 所有历史记录、板块轮动表、统计全部回来

> 没有 Token 也能用：设置 → 备份与导出 → 「导出全部数据（JSON）」，在新电脑用「导入 JSON」恢复。

## 二、Token 怎么建（一次性，约 1 分钟）

1. 打开 <https://github.com/settings/personal-access-tokens/new>
2. **Token name**：填 `trade-log`
3. **Expiration**：90 天（到期重新建一个即可）
4. **Repository access**：选 `Only select repositories` → 勾选 **`liang-trade-log-data`**
5. **Permissions** → `Repository permissions` → 找到 **Contents** → 选 **Read and write**
6. 拉到底点 **Generate token**，复制 `github_pat_...` 开头的那串

把它粘到网页「设置 → GitHub 同步」里保存。

**口令（进入锁）**
- 打开网页会先要求口令，输对了才显示内容
- 口令只以校验值形式存进数据文件，明文不会出现在任何地方（包括 GitHub 上）
- 改口令：设置 → 进入口令 → 填新的 → 保存；留空保存 = 取消口令
- 忘了口令：数据还在云端，按上面「换电脑」的流程清空本机数据再拉取即可（设置 → 危险操作 → 清空本机数据 → 点拉取）
- 它是防随手翻看的，不是加密：能打开浏览器开发者工具的人依然能读到本机缓存

**安全提醒**
- Token 只存在你当前这台电脑的浏览器里，不会写进数据文件、不会进仓库
- 只授权这一个仓库的 Contents 权限，泄露了影响也有限
- 公用电脑不要填 Token，改用「导入 / 导出 JSON」

## 三、每天怎么用

一共 5 个页签：**今日 / 回顾 / 周度 / 月度 / 设置**。「今日」下面再分 4 个小页签：当晚清单 / 次日盘中 / 盘后复盘 / 成交记录。

| 时段 | 打开哪个页签 | 做什么 |
|---|---|---|
| 收盘后 15:30–16:00 | 今日 → 当晚清单 | 填指数状态 → 抄日报主线 → 逐个品种过三条标准（自动判保留/剔除）→ 选 2–3 个 → 写条件单 → 检查持仓 |
| 次日 10:00 / 13:30 / 14:15 | 今日 → 次日盘中 | 看盘仍看三次，但**只记每个品种当天的最终结果**，一个下拉搞定 |
| 收盘后 16:00–16:15 | 今日 → 盘后复盘 | 对答案 → 记板块轮动一行 → 顺手在「成交记录」填当天盈亏 |
| 周日 30 分钟 | 周度 | 胜率、盈亏比、违规次数自动算，填品种池和仓位 |
| 月底 1 小时 | 月度 | 月度盈亏、最大回撤、一致/不一致胜率对比、规则调整 |
| 随时回看 | 回顾 | 顶部是板块轮动表（按日期倒序，可导出 CSV），下面是总胜率/盈亏比/回撤 |

**当日产出**：点右上角「打印一页纸」，A4 打印出来贴在电脑旁。

每个页签顶部都有一条**时间提示**，会按当前钟点告诉你「现在该做什么」：到点了显示蓝色「现在」，还没到显示「建议 下一个时间点」，错过了显示灰色提示。周度页在周日提醒、月度页在月底提醒。

## 四、为什么按钮这么少

这版专门做过一次「收口」，原则是：**能自动判的不让你手打，能选一次的不让你选三次。**

- **不加「已完成」勾选框**——每个卡片右上角的绿色「已完成」是按内容自动判的，填了就算完成
- **盘中打卡不再分三次填**——10:00 / 13:30 / 14:15 照旧看三次，但只记每个品种的**当天最终结果**（一个下拉：有信号执行了 / 有信号没做 / 无信号没动 / 违规）
- **不单设「板块轮动」页签**——它已经并进「回顾」页顶部，每天填完自动汇总成表
- **复盘从 5 组压到 3 组**——原来「信号出没出」「抓没抓到」是两个选择，现在合成一个；「一致/不一致」「盈利/亏损」也合成一个
- **验证「远离均线不要追」那类补充项默认收起**——需要时点开，平时不占版面

老的记录不用管：旧格式（按 10:00 / 13:30 / 14:15 分开存）读进来会自动合并成新格式，按严重程度取最高的那条，备注用「；」拼起来。

## 六、自动判定规则（代码里写死的）

- **品种保留**：日线多头排列 ✔ + 偏离 5/20 日均线 < 2% + 15 分钟粘合 ✔，三条全满足才保留，任一不满足自动剔除
- **观察清单**：超过上限（默认 3）不允许再加
- **胜率** = 盈利笔数 ÷ 总笔数
- **盈亏比** = 平均盈利 ÷ 平均亏损（同时算 profit factor）
- **最大回撤**：按已实现盈亏的累计曲线算
- **连亏告警**：连续 3 笔亏损 → 回顾页和月度页红色提示「暂停一周」
- **一致 vs 不一致**：成交记录里标了「与老师一致 / 不一致」，长期自动对比谁的胜率高
- **盘中状态**：一个品种一天只存一条最终状态，改了下拉就覆盖，不会重复计数
- **违规汇总**：盘中页勾的违规，周日自动进「检查纪律执行」卡片

资金参数（总资金 40 万、单笔 ≤ 1 万、保证金 ≤ 60%、同时持仓 ≤ 2）在 **设置** 里随时可改。

## 八、常见问题

**Q：上传报 409 冲突？**
云端文件被别处改过（比如另一台电脑刚上传）。先点「拉取」取回最新版，再重新上传。

**Q：上传报 403 / 404？**
Token 没有这个私有仓库的 Contents 读写权限，或仓库名 / 用户名填错。到设置页点「测试连接」会告诉你具体原因。

**Q：数据会丢吗？**
三重保险：① 私有仓库的每次上传都是一个 commit，可以回退到任意历史；② 本机浏览器缓存；③ 设置页每次上传前自动留本地快照（最多 8 份），可一键恢复。另外建议每月「导出 JSON」存一份到网盘。

**Q：手机上能用吗？**
能。页面做了响应式：表格在手机上变成卡片、复盘的分段按钮变成可换行的独立胶囊，不会横向溢出。手机上同样需要填一次 Token。盘中打卡在手机上就是一个下拉 + 一个备注框。

**Q：没有网络能记吗？**
能。所有输入先存本机，联网后再点「上传」。
